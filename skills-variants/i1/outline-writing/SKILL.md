# 全篇执行大纲 Skill

你写的是上游任务的最终 artifact，不是正文。下游正文任务只看到这份大纲，
所以必须让每个小节的边界、人物、目标、冲突和结束状态都能独立执行。

## S1. 忠实提取原文

先用 `read_task_input` 并显式传入 `field: source_text` 读取完整原文。只提取原文已有的人物、事件、因果、反转、
情绪与叙述节拍；不新增事件、证据、动机、对白或世界观。

按原文推进顺序划成 **8–30 个编号小节**。小节是生产单位，不等于地点或时间连续场景。

先识别全篇主要阅读动力，并为每节路由模式：

- `快叙`：反常事实、过往结果和移动用最短结果句推进；不要把每段前史还原成完整场景；
- `冲突场景`：阅读动力来自对白交锋、关系切割或权力变化，不可概述的轮次需要细写；
- `悬疑发现`：每节必须带来新信息、淘汰旧解释或改变认知；
- `现实情感`：关系、生活处境和迟来选择是主动力，允许必要情绪余波；
- 无法归类才用 `自定义`，并在目标里写清主动力。

**一个小节承载一个主要状态变化。** 状态变化包括：因果推进、关系位移、信息揭示、
选择兑现或情绪认知发生作用。划分顺序固定如下：

1. 先逐项核销原文的因果台阶、关系位移、反转、结局，以及读者应该感到或理解的重点；
2. 同一段里若有两个各自能形成停点、下一节可从其后承接的关键变化，**必须拆成两节**；
   换叙事视角、跨显著时间、从主线转入人物番外、再从人物余波转入执法/后记结局，
   都是新的独立叙事单元，**必须另起编号小节，不得与前一条主线或后一条结局合并**；
3. 只有过场、氛围铺垫、重复反应，且拿掉后不改变任何状态时，才并入相邻小节；
4. 不得为减少小节数而把尚未核销的重点并掉。惜字不是把故事压成情节梗概，
   是先让应该发生、应该感到和应该被理解的内容完整，再去掉没有作用的重复。

## S2. 固定写法

每个小节使用以下字段，字段名和顺序不得改变：

```
1. 雨夜赴约
变化：林越只在准备赌局 → 林越已经来到必须摊牌的门外
重点：P0 P001
展开：轻过渡
模式：快叙
容量：对白轮次 0；动作反馈闭环 1；认知转折 1；事后余波 0
出场：林越
目标：让孤注一掷成为可见行动并建立本篇阅读动力
冲突：凭证经不起细看，但已经没有退路
结束状态：林越推门看见老周
信息控制：只让读者知道凭证有问题，不解释伪造过程
```

### 重点

- `P0 P001`：主要阅读动力、关键因果、关系翻面、反转或结局；第二个 token 必须匹配 `P\d{3}`，全篇唯一；
- `P1 P002`：为 P0 建立必要触发、推进或情绪/读者压力；第二个 token 必须匹配 `P\d{3}`，全篇唯一；
- `bridge`：只负责时空、动作或状态连接，不承载新的主要变化。

`重点` 行只能包含上述机器值，不加括号、方括号、中文说明或标题；重点说明写进同节 `目标`。

每个 P0/P1 只有一个主要兑现小节。后文再次提到不重新使用同一个 ID。按首次出现从 `P001` 起顺序编号，
P0/P1 共用同一编号序列，不按类别重新从 1 开始。**先完成全篇内容，再从第一节到最后一节只扫描 `重点` 行，
把遇到的每个 P0/P1 依次重写为 `P001`、`P002`、`P003`……；不得按重要性、P0/P1 类别或原文编号跳号。**

### 展开

- `细写`：不可摘要的冲突轮次、关键选择、关系/认知翻面或主要阅读回报；
- `标准`：一个完整变化闭环，需要正文动作/对白，但不是全篇峰值；
- `轻过渡`：快叙、移动、前史结果、必要连接或短余波；用最短充分表达，不还原成完整场景。

全篇必须至少出现两种展开档。不要为了平均篇幅把所有节标成标准或细写。

### 容量

容量是语义载体，不是句子数：

- 对白轮次：问答双方各算一个轮次，上限 8；
- 动作反馈闭环：动作必须得到反馈并改变下一反应，上限 4；
- 认知转折：新信息必须改变人物判断，上限 4；
- 事后余波：主变化完成后的最短消化/决定加固，上限 2。

重复解释、静态物件枚举、普通移动和同一结论改写不计容量。容量超过上限时拆节或去重，
不能把超额数字交给正文模型。

### 信息控制

有反转时只记录当前小节需要避免提前泄露的答案；这是叙事提示，不授予正文 Agent 读取范围或事实权限。
正向 allowlist、未授权事实审计和未来小节隔离属于 I4，本阶段不输出也不宣称实现。

要求：

- 编号连续，条目数在 8–30；
- 每节写全变化、重点、展开、模式、容量、出场、目标、冲突和结束状态；
- 有反转时额外写清信息控制，避免前文泄底；
- 只写规划，不写可直接复制进正文的对白或景物散文；
- 相邻小节的结束状态与下一节起点能接上。

## S3. 提交前机械规范化

先完成内容核销，再做一遍只检查格式、不改变故事取舍的全篇规范化：

1. 从第 1 节到最后一节连续编号，标题行只写 `N. 标题`；
2. 每节逐行核对这九个必填字段恰好存在：`变化 / 重点 / 展开 / 模式 / 容量 / 出场 / 目标 / 冲突 / 结束状态`；无人出场也写 `出场：无`；
3. `重点` 只保留 `bridge` 或 `P0 PNNN` / `P1 PNNN`，再按首次出现把全部 P0/P1 ID 从 `P001` 连续重排；
4. `模式` 只能逐字使用 `快叙 / 冲突场景 / 悬疑发现 / 现实情感 / 自定义`；不得写同义词或追加说明；
5. 最后一节必须是 P0 且明确兑现原文结局；结局前至少还有一个 P0；
6. `容量` 逐字保持示例里的四项、顺序和全角分号；数字不得超过 8/4/4/2。

然后再按语义自检：
- [ ] 每个小节的变化都写成“起始状态 → 新状态”。
- [ ] P0/P1 ID 严格写成 `P0 P001` / `P1 P002`，全篇按首次出现顺序编号且唯一；bridge 不冒充重点；主要阅读动力和结局至少各有 P0。
- [ ] 全篇至少有两种展开档；轻过渡没有被标成完整场景，关键冲突没有被压成摘要。
- [ ] 每项容量不超过 8/4/4/2，且没有把重复解释、普通移动当容量。
- [ ] 每节只有一个主要状态变化；两个可独立停住的关键变化没有挤在同一节。
- [ ] 每次换叙事视角、跨显著时间、进入番外或后记，都另起编号小节；没有与相邻主线合并。
- [ ] 没有只承载过场、氛围或重复反应而不改变任何状态的空节。
- [ ] 所有重点先完整核销，再做合并；没有压成情节梗概。
- [ ] 小节数为 8–30，编号连续。
- [ ] 每节九个必填字段齐全；有反转时另有信息控制。
- [ ] 没有新增原文不存在的事实。
- [ ] 没有正文散文或可直接照抄的对白。
- [ ] 相邻小节衔接，最后一节兑现原文结局。
- [ ] 字数在本槽位约束内。

完成后调用 `complete_assignment` 提交一份完整大纲。
