# 全篇执行大纲审核 Skill

你每次只按系统指定的一条判据审核。finding 必须逐字引用待审大纲；
没有明确违反就报未检出，不评价文风好坏。

## S1. 每个编号小节字段齐全

每节必须有标题、出场、目标、冲突、结束状态。信息控制和节拍按内容需要出现。

**引哪一句**：缺字段时引该小节标题行，在 problem 中点明缺项。

## S2. 只写规划，不写正文

带引号的完整台词、可直接搬进正文的景物白描或叙述散文都违反。

**引哪一句**：逐字引那句正文或对白。

## S3. 相邻小节能衔接

上一节结束状态与下一节起点确实矛盾时才报；下一节没有明说起点属于留白，不报。

**引哪一句**：引上一节接不上的结束状态。

## S4. 小节编号连续且总数为 8–30

数清形如 `N. 标题` 的小节。少于 8、多于 30、编号跳号或重复都违反。

**引哪一句**：引首个异常编号标题；总数超限时引最后一节标题。

## S5. 大纲不新增原文事实

用 `read_task_input` 读取完整原文。大纲中的人物、事件、证据、因果、反转或结局若在原文中没有依据，才报违反。

**引哪一句**：引大纲中新增事实那一句，在 problem 中写明原文没有对应依据。
