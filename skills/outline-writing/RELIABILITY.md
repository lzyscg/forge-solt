# outline-writing 分节规则的实测可靠度

> 这份记录不放进 `SKILL.md`：可靠度说明会进入模型上下文，等于先告诉模型哪些规则可能失效。

## S4 分节粒度实验（2026-09-02）

使用同一条真实 `outline-writing` ReplayInput；生产基线 n=3，三轮变体各 n=3。全部失败与逐字审计保留，无 best-of。

| run | 可接受 | 失败形态 |
|---|---:|---|
| baseline | 2/3 | 一份使用中文序号，确定性 outline 对账不识别 |
| variant r1 | 2/3 | 妻子番外与警察后记合并 |
| variant r2 | 2/3 | 新学生主线与妻子番外合并 |
| variant r3 | **3/3** | 无；21–24 节，全部出场/目标/冲突/结束状态字段齐全 |

r3 的有效改动不是为当前故事列专名，而是把以下一般边界改成可执行规则：换叙事视角、跨显著时间、
从主线进入番外、从余波进入执法/后记，必须另起编号小节。三份均独立保留新学生线、妻子番外和警察后记。

**证据强度限制**：只有一个真实故事、每条件 n=3。它足以提升为当前生产规则，不足以声称跨题材稳定；
S6 后的多故事整篇仿写验收必须再次检查该边界。
